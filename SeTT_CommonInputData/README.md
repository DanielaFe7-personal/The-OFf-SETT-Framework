# SeTT_CommonInputData

Input datasets shared by all SeTT modules. This folder is the source of  spectral indices, population data, and study area boundaries.

## Contents

SeTT_CommonInputData/



    ├── Spectral_Indices_Dataset/ # Spectral indices per Study Area (Evian, Fribourg, Grand Geneve)
    	├── Three families: LIS, LST, and CLC
    ├── Population_Dataset/ # Population datasets for the same Study Areas
    ├── StudyAreas_Boundaries_Map/ # GeoPackage (.gpkg) boundaries for mapping

---



## Folders

- Spectral_Indices_Dataset
  - Time-series spectral indices organized by Study Area: Evian, Fribourg, Grand Geneve.
  - CSV files with date, index_name (e.g., NDVI, EVI, NBR), index_value, and spatial refs.

- Population_Dataset
  - Population data aligned to the same Study Areas 
  
- StudyAreas_Boundaries_Map
  - GeoPackage (.gpkg) layers with polygon boundaries for each Study Area.
